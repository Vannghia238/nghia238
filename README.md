\\## ⚙️ Quy trình CI/CD







1\\. Chỉnh sửa mã nguồn trên máy tính.



2\\. Sử dụng Git để commit và push code lên nhánh `main`.



3\\. GitHub Actions tự động chạy workflow.



4\\. Website được triển khai lên GitHub Pages.







\\\*\\\*Luồng triển khai:\\\*\\\*







`Write Code → Git Commit → Git Push → GitHub Actions → GitHub Pages`
